## Challenge
Tip Calculator using functions

## What I Learned
- **Data Type Casting:** How to properly convert user input from strings (`str`) to integers (`int`) or decimals (`float`) to perform math.
- **Function Structure:** How to design functions with parameters to accept inputs and use `return` values to pass data back.
- **Scope & Code Reuse:** How separating logic into independent functions makes code cleaner and easier to debug.

## Difficulties
- **Type Errors:** Forgetting that `input()` always returns a string, which caused errors when trying to do calculations.
- **Return vs. Print:** Confusing what `print()` does (showing text) with what `return` does (passing data inside a function).
- **Scope Misunderstandings:** Trying to use a variable inside one function that was defined inside a completely different function.

## How I Solved Them
- **Explicit Conversion:** Used `int()` and `float()` right after gathering inputs to ensure they were ready for math operations.
- **Trace & Debug:** Followed the data flow step-by-step to make sure functions were returning values to variables instead of just printing them to the screen.
- **Passing Arguments:** Learned to pass variables into functions explicitly as arguments instead of assuming they could be accessed globally.

## Key Takeaway
Breaking a problem down into **Input → Process → Output (IPO)** simplifies coding.
